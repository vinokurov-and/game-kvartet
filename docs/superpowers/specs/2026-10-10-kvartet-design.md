# «Квартет» — спецификация v1

Дата: 2026-10-10. Статус: согласовано с владельцем (механика, название, объём v1, без сервера).
Исследования и обоснование — Obsidian `~/app-store/Ресёрчи/Мобильная игра для App Store и RuStore — стратегия (2026-10).md`,
чеклист модерации — `~/app-store/Знания/Модерация игры с рекламой — App Store и RuStore.md`.

## 1. Что это

Ежедневная русская словесная головоломка. 16 слов нужно разложить на 4 группы по 4 по скрытому признаку
(литература, кино, идиомы, двойные значения, игра слов). Одна головоломка дня на всех — повод обсудить и
поделиться результатом. Бесплатно, монетизация — только Yandex Mobile Ads.

- Имя в сторах: «Квартет: слова и связи» (уточнить при подаче). Bundle ID: `com.kvartet.app`.
- Платформы: **iOS первым** (App Store, тест через TestFlight), RuStore — позже тем же кодом.
- Аудитория: РФ, 30–55 лет, короткие сессии.

## 2. Объём v1

### 2.1 Квартет дня
- Публикуется в 10:00 МСК; одна головоломка на всех (определяется датой по МСК, не по часовому поясу устройства).
- Игрок выбирает 4 слова → «Проверить». Верно — группа схлопывается в цветную плашку с названием темы.
  Неверно — минус одна ошибка; «Почти!» если 3 из 4 верны. Ошибок — 4.
- 4 уровня сложности групп, свои цвета (жёлтый → зелёный → синий → фиолетовый — финальные цвета из дизайн-системы).
- Перемешать слова; снять выделение.
- После завершения — экран результата: разобранные группы, серия, кнопка «Поделиться», таймер до следующей.

### 2.2 Шеринг
- Текст: «Квартет №123» + сетка эмодзи по попыткам (без слов) + ссылка на стор.
- Картинка того же без спойлеров (react-native-view-shot) — через системный share sheet.

### 2.3 Серия и статистика
- Сыграно, % побед, текущая и лучшая серия, распределение ошибок (0–4).
- Хранится локально.

### 2.4 Архив
- Прошлые дни с даты запуска. Последние 3 дня — бесплатно, старше — за rewarded (один просмотр = один день).
- Результаты архива не влияют на серию.

### 2.5 Тренировка
- Наборы по темам (литература, кино, идиомы, …), бесконечно, без влияния на статистику дня.
- Нужна для 4.2 «lasting value» и как инвентарь рекламы.

### 2.6 Реклама (Yandex Mobile Ads)
- Rewarded, только по кнопке: подсказка (открыть одно слово группы или тему группы), вход в архивный день,
  +4 ошибки после проигрыша.
- Interstitial: только в тренировке, не чаще 1 раза на 2–3 головоломки и не чаще раза в 90 с.
- Квартет дня — без interstitial. Первая сессия — без рекламы вообще.
- Баннер в v1 не используем.
- iOS: ATT-промпт до инициализации рекламы, награды не зависят от ответа. Только Yandex Mobile Ads (без VK-медиации на первом сабмите).

### 2.7 Прочее
- Онбординг: 3 экрана-примера «как играть» + интерактивная мини-головоломка.
- Настройки: звук, вибрация, тема (светлая/тёмная), «Как играть», политика конфиденциальности, связь.
- Без регистрации и сбора данных с нашей стороны.

## 3. Архитектура

- Expo SDK 54, Expo Router, TypeScript strict, Tamagui, Reanimated (анимация плиток), Zustand + MMKV (прогресс),
  luxon (даты МСК), `yandex-mobile-ads` (EAS dev build; в Expo Go реклама не работает).
- **Без сервера.** Головоломки — JSON в бандле приложения (год вперёд), обфусцированы (не шифрование —
  защита от случайного подсмотра). Добавление и правки — через EAS Update (каналы preview/production).
- Офлайн полностью.
- Аналитика v1 — нет (меньше данных в App Privacy). Метрики — из кабинета РСЯ и App Store Connect. Решение
  пересмотреть после TestFlight.

### Формат головоломки
```json
{ "id": 123, "date": "2026-11-15",
  "groups": [
    { "level": 1, "theme": "Пьесы Чехова", "words": ["ЧАЙКА","ИВАНОВ","ДЯДЯ ВАНЯ","ТРИ СЕСТРЫ"] },
    { "level": 2, "theme": "…", "words": ["…"] },
    { "level": 3, "theme": "…", "words": ["…"] },
    { "level": 4, "theme": "…", "words": ["…"] }
  ] }
```
Валидация: 16 уникальных слов, ровно 4×4, длина слова ≤ 12 символов, у каждого слова ровно одна правильная группа.
Хорошая головоломка содержит «ловушки» — слова, подходящие к нескольким темам, но верных разбиений одно.

### Контент-пайплайн (локально, вне приложения)
1. Скрипт генерации через bothub (OpenAI-совместимый, ключ в `.env`, не в клиенте) — пачка кандидатов.
2. Автовалидация (формат, дубли, повторы слов за последние 30 дней).
3. Ручной отбор (одобрить/отклонить/править) — делает агент, владелец не участвует.
4. Одобренные → `content/puzzles.json` в репо → сборка/OTA.
Стартовый запас — 90 дней + 10 наборов тренировки.

## 4. Модерация (App Store первый)
По чеклисту из базы: своя визуальная идентичность, русский контент, ежедневный режим + прогрессия; 12+, не Kids;
privacy policy URL; скриншоты реального геймплея; Review Notes — чем отличаемся от Wordle-клонов, монетизация
только реклама, IAP нет. **Подача — после решения Apple по aiStella.**

## 5. Вне v1
