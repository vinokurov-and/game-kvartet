# План реализации «Квартет» v1

Спека: `docs/superpowers/specs/2026-10-10-kvartet-design.md`. Порядок — каждая задача даёт работающий результат,
проверяемый на iPhone (dev build) или тестами. Коммит после каждой задачи.

## Этап 1. Каркас
- [x] 1. Expo SDK 54 + TypeScript strict + Expo Router; `app.json`: имя «Квартет», bundle `com.kvartet.app`, scheme `kvartet`.
- [x] 2. Тема «необрутализм» (токены цветов, шрифты Unbounded/Onest через `@expo-google-fonts`), светлая/тёмная.
- [x] 3. Базовые компоненты: `BrutalBox` (обводка + жёсткая тень + вдавливание), `BrutalButton`, `Tile`, `GroupBar`.
- [ ] 4. ESLint/Prettier, Jest (или vitest) для логики, `npm test`.
- [ ] 5. EAS: проект, профили `development`/`preview`/`production`, каналы обновлений; первая dev-сборка на iPhone.

## Этап 2. Игровая логика (сначала тесты)
- [ ] 6. Типы `Puzzle`, `Group`; валидатор головоломки (16 уникальных, 4×4, длины).
- [ ] 7. Движок партии (чистые функции): выбор/снятие, проверка, «почти» (3 из 4), ошибки, победа/поражение, перемешивание с seed.
- [ ] 8. Дата квартета по МСК (luxon): номер дня, какая головоломка сегодня, время до следующей.
- [ ] 9. Обфускация/деобфускация `puzzles.json` (сборочный скрипт + рантайм).

## Этап 3. Экран игры
- [ ] 10. Игровое поле 4×4 + разгаданные группы сверху, кнопки «Перемешать / Снять / Проверить», индикатор ошибок.
- [ ] 11. Анимации: вдавливание, схлопывание группы, тряска при ошибке, «Почти!»; haptics; reduce motion.
- [ ] 12. Состояние партии в Zustand + MMKV (продолжить незаконченную после перезапуска).

## Этап 4. Результат, статистика, шеринг
- [ ] 13. Экран результата: сетка попыток, серия, % побед, сыграно, таймер до следующего.
- [ ] 14. Статистика и серия (локально), распределение ошибок.
- [ ] 15. Шеринг: текст с эмодзи + картинка (react-native-view-shot) через системный share sheet.

## Этап 5. Архив, тренировка, онбординг, настройки
- [ ] 16. Архив: список дней, бесплатные последние 3, остальные — заглушка «за рекламу» (подключим в этапе 6).
- [ ] 17. Тренировка: наборы по темам, бесконечный режим.
- [ ] 18. Онбординг «как играть» + интерактивная мини-головоломка.
- [ ] 19. Настройки: звук, вибрация, тема, «как играть», политика, поддержка.

## Этап 6. Реклама
- [ ] 20. Партнёрский кабинет РСЯ: блоки rewarded + interstitial для `com.kvartet.app` (владелец/агент через браузер).
- [ ] 21. `yandex-mobile-ads` + config plugin; ATT-промпт до инициализации; Info.plist (SKAdNetwork, NSUserTrackingUsageDescription).
- [ ] 22. Rewarded: подсказка, архивный день, +4 ошибки. Interstitial в тренировке с частотными ограничениями. Первая сессия без рекламы.

## Этап 7. Контент
- [ ] 23. Скрипт генерации через bothub + автовалидация + повтор слов за 30 дней.
- [ ] 24. Отбор 90 дней + 10 наборов тренировки, запись в `content/`.

## Этап 8. Публикация
- [ ] 25. GitHub Pages: политика конфиденциальности (с раскрытием Yandex Mobile Ads) и поддержка.
- [ ] 26. Иконка, сплэш, скриншоты 6.5"/6.9", описание, ключевые слова, Review Notes.
- [ ] 27. App Store Connect: карточка, App Privacy (данные SDK Яндекса), 12+; TestFlight.
- [ ] 28. Сабмит — **после решения Apple по aiStella**.
