Русский

Приложение не требует регистрации и не собирает персональные данные само.

Для показа рекламы используется SDK Yandex Mobile Ads (ООО «Яндекс»). SDK может обрабатывать: идентификатор рекламы (IDFA) — только если вы дали разрешение в системном диалоге отслеживания; технические данные устройства (модель, версия ОС, язык, IP-адрес); данные о взаимодействии с рекламой. Обработка описана в политике Яндекса.

Прогресс в игре хранится только на вашем устройстве.

English

The app does not require an account and does not collect personal data on its own.

Ads are served by the Yandex Mobile Ads SDK (Yandex LLC). The SDK may process: the advertising identifier (IDFA) — only if you allowed tracking in the system prompt; technical device data (model, OS version, language, IP address); ad interaction data. See the Yandex policy.

Game progress is stored only on your device.
